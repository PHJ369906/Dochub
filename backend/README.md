# Backend - SpringBoot 项目

基于 SpringBoot + Sa-Token 的后端项目

## 技术栈
- SpringBoot 3.x
- Sa-Token (鉴权框架)
- Spring Data JPA
- MySQL
- Redis
- Maven

## 开发环境要求
- JDK 17+
- Maven 3.6+
- MySQL 8.0+
- Redis

## 启动项目
```bash
mvn spring-boot:run
```

## 构建项目
```bash
mvn clean package
```

## API文档
启动项目后访问: http://localhost:8080/doc.html
